# 21 · SuonaOS 视觉语言

> 脚本：`scripts/22-suona-identity.sh`、`scripts/15-rounding.sh`
> 需求：`REQ-34`　决策：`ADR-36`

## 0. 一句话

SuonaOS 像一把**唢呐**：深色木腔、黄铜喇叭口、瓷面吹嘴。
它不长得像任何别的系统——这是要求，不是副作用。

## 1. 为什么明确「不做 macOS」

三条理由，都是工程理由而不是审美偏好：

| 理由 | 说明 |
|---|---|
| 会破坏可用性 | WhiteSur 全套曾在 11-03 上线，随后在卡顿排查中整批回退（ADR-07），再恢复等于重走一遍未知风险 |
| 维护成本高 | 整套主题跟 GNOME 版本强绑定，GNOME 51 一起就得重做；本项目已因主题与 Kimpanel 冲突付过一次代价（ADR-05） |
| 没有识别度 | 抄来的外观无法沉淀资产；而音效主题、壁纸、圆角令牌已经是本项目独有的东西 |

因此，「媲美 macOS」在体验层面要实现的是**跟手、清晰、一致**，不是**长得像**。

## 2. 材质线索

| 材质 | 视觉转译 | 用途 |
|---|---|---|
| 木腔 | 深棕、低饱和、哑光 | 深色背景、正文强调 |
| 黄铜 | 暖橙金、只在焦点处出现 | 强调色、选中态、进度 |
| 瓷面 | 米白、微暖、干净 | 浅色背景、卡片、留白 |

## 3. 色板

| 角色 | 深色 | 浅色 | 说明 |
|---|---|---|---|
| 背景 | `#1A1613` | `#F7F4EF` | 不用纯黑纯白 |
| 表面 | `#2A2320` | `#FFFFFF` | 弹层、卡片 |
| 主文字 | `#F5F0E8` | `#1C1917` | 对比度 ≥ 7:1 |
| 次文字 | `#6B5F55` | `#6B5F55` | 说明、时间戳 |
| 强调 | `#C8873F` | `#A85A22` | 铜色，**全系统唯一强调色**；不可用时退 `orange` |
| 成功 / 警告 / 错误 | `#2E7D32` / `#B26A00` / `#C62828` | 同 | 只用于状态，不做装饰 |

**单一强调色规则**：开关、选中、焦点环、进度条必须同色。出现第二种强调色即视为不一致。

## 4. 圆角梯度

| 层级 | 半径 | 落地位置 |
|---|---|---|
| 窗口 / 弹层 / 通知 | 14px | `~/.config/gtk-4.0/gtk.css`、`Suona-Round` |
| 快捷设置 | 18px | `Suona-Round` 的 `.quick-settings` |
| Dock 背景 | 20px | `Suona-Round` 的 `.dash-background` |

只允许这三个值。改半径只改一个源头：`./scripts/15-rounding.sh --install --radius N`。

## 5. 窗口与控件

- **按钮在右侧**：`:minimize,maximize,close`。左侧红绿灯是 macOS 符号，已按 ADR-36 清除。
- **不做全局菜单栏**：GNOME 无此结构，硬做得引入扩展（违反 ADR-24）。
- **不做 Launchpad 式图标墙**：概览已能搜索与启动，重复造一个只会增加维护面。
- **图标不整套替换**：Yaru 保持，未来自有图标按「木/铜/瓷」三材质单点补充，不绑架全系统。

## 6. 文字

| 项 | 规则 |
|---|---|
| 字体族 | **不改**：界面 `Adwaita Sans 11`，等宽 `Ubuntu Sans Mono 11` |
| 层次 | 靠**字重与间距**拉开，不靠放大字号 |
| 渲染 | 由 `23-font-render.sh` 统一 hinting / rgba / lcdfilter（见 `docs/22`） |
| 禁止 | 不用发光字、不用渐变字、不用描边字 |

## 7. 动效

- 统一时长与缓动：窗口、弹层、快捷键反馈用同一条曲线。
- 去掉弹跳与过冲，保留「轻」的收束感。
- **每一项动效开销都要有 `docs/20` 的采样数据支撑**，不能凭手感增加。

## 8. 声音与图像

| 资产 | 与视觉的呼应 |
|---|---|
| Suona 音效（34 事件，木腔/瓷击/哨片/低木） | 木腔对应深棕，瓷击对应米白，铜响对应强调色 |
| 水系壁纸（14 张，3072×1920） | 低饱和蓝做冷静底色，不抢铜色强调 |
| GRUB Vimix | 只做暗底浅字，不引入第三种风格 |

## 9. 落地与验收

```bash
./scripts/22-suona-identity.sh --install     # 强调色 / 按钮位置 / 光标收敛
./scripts/22-suona-identity.sh --status
./scripts/15-rounding.sh --install           # 14/18/20 梯度
./scripts/99-verify.sh                       # 「视觉令牌」段
```

验收断言（`99-verify.sh` 已实现）：

1. `button-layout` 不含左侧布局（`:minimize,maximize,close` 形式）
2. `cursor-theme` 不是 WhiteSur
3. `~/.local/share/icons/WhiteSur-cursors` 不存在
4. 若本机支持 `accent-color`，其值在支持集内且与 `identity.conf` 记录一致
5. 若装了圆角覆盖层，半径为 14px

## 10. 禁止清单

- ❌ 红绿灯按钮、顶部全局菜单、Launchpad 仿制、Dock 放大特效
- ❌ 毛玻璃滥用（只允许顶栏与概览）
- ❌ 高饱和霓虹、紫粉渐变、发光阴影
- ❌ 整套主题替换（WhiteSur / MacTahoe 等）
- ❌ 为「像某个系统」而牺牲可读性或维护性

## 11. 回滚

```bash
./scripts/22-suona-identity.sh --restore    # 三项 gsettings + 光标目录
./scripts/15-rounding.sh --restore          # 圆角覆盖层
```

两项互不依赖；只回滚其中一项不会影响另一项。
