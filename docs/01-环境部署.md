# 01 · 环境部署

> 阶段目标：建立可重复、可回滚的优化工程环境。完成本阶段后，后续所有改动都通过脚本执行，
> 每一步都有备份、日志和变更登记。

## 1. 前置条件

| 条件 | 检查命令 | 期望 |
|---|---|---|
| 系统版本 | `lsb_release -ds` | Ubuntu 26.04 LTS |
| 会话类型 | `echo $XDG_SESSION_TYPE` | wayland |
| 磁盘可用 | `df -h /` | > 50G |
| 网络 | `wget -q --spider https://mirrors.tuna.tsinghua.edu.cn && echo OK` | OK |

### 免密 sudo（自动化前提）

本项目的脚本需要无人值守执行 `apt`、`systemctl`、写 `/etc`。配置方式：

```bash
sudo tee /etc/sudoers.d/99-codebuddy-nopasswd >/dev/null <<'EOF'
suonaos ALL=(ALL) NOPASSWD: ALL
EOF
sudo chmod 0440 /etc/sudoers.d/99-codebuddy-nopasswd
sudo visudo -c          # 校验语法，必须输出 parsed OK
```

撤销：

```bash
sudo rm /etc/sudoers.d/99-codebuddy-nopasswd
```

> 安全提示：`NOPASSWD: ALL` 意味着当前用户的任何进程都能提权。个人开发机可接受，
> 多人共用或生产环境请改为白名单：
> `suonaos ALL=(ALL) NOPASSWD: /usr/bin/apt-get, /usr/bin/systemctl, /usr/bin/tee`

## 2. 目录规范

```
linux-tune_SuonaOS/
├── baseline/<RUN_ID>/     基线快照，只读，不覆盖
├── backup/<RUN_ID>/       被改动文件的原始副本，路径层级完整保留
│   ├── files/etc/...      单文件备份
│   └── dirs/home/...      目录备份
├── logs/
│   ├── <RUN_ID>-<脚本名>.log   每次运行的完整日志
│   └── changes.tsv             变更登记表：时间 / 原路径 / 备份相对路径
└── scripts/
```

`RUN_ID` 格式为 `YYYYmmdd-HHMMSS`，同一次运行的所有备份归入同一目录，
回滚时只需指定这一个 ID。

## 3. 公共函数库

`scripts/lib/common.sh` 提供：

| 函数 | 作用 |
|---|---|
| `log/ok/warn/die` | 带时间戳与颜色的日志，同时写入 `logs/` |
| `step` | 打印阶段分隔符 |
| `have <cmd>` | 判断命令是否存在 |
| `require_sudo` | 校验免密 sudo，缺失时给出修复命令 |
| `backup_file <path>` | 备份单文件并登记 |
| `backup_dir <path>` | 备份目录并登记 |
| `apt_install <pkgs...>` | 跳过已安装包，只装缺失项 |
| `pkg_installed <pkg>` | 查询包状态 |

所有脚本统一以这两行开头：

```bash
set -o pipefail
source "$(dirname "${BASH_SOURCE[0]}")/lib/common.sh"
```

> 踩坑记录：不要在采集脚本里用 `set -u`。基线脚本引用 `$QT_QPA_PLATFORM` 时该变量不存在，
> 在 `set -u` 下会直接终止整个脚本（表现为脚本"静默卡死"）。

## 4. 执行步骤

### 4.1 采集基线

```bash
./scripts/00-preflight.sh
```

只读操作，不修改任何文件。产出 `baseline/<RUN_ID>/` 下 26 个文本文件与 `SUMMARY.md`。

### 4.2 安装基础工具链

```bash
./scripts/01-install-base.sh
```

安装内容分五组：

| 分组 | 包 |
|---|---|
| 版本控制/下载 | `git` `curl` `ca-certificates` `gnupg` |
| 编译工具链 | `build-essential` `pkg-config` |
| 终端常用 | `vim` `tmux` `zsh` `htop` `tree` `jq` `unzip` `zip` `rsync` |
| 现代 CLI | `ripgrep` `fd-find` `bat` `fzf` `btop` |
| Python 基座 | `python3-pip` `python3-venv` `pipx` |
| 硬件监控 | `lm-sensors` |
| 主题编译 | `sassc` `libglib2.0-dev-bin` `dconf-cli` |
| GNOME 调整 | `gnome-tweaks` `gnome-shell-extension-manager` |

其中 `sassc` 与 `libglib2.0-dev-bin`（提供 `glib-compile-resources`）是后续编译 WhiteSur 主题的**硬依赖**，缺一不可。

### 4.3 命名修正

Ubuntu 把 `fd`、`bat` 改名成 `fdfind`、`batcat`，脚本会在 `~/.local/bin` 建软链还原短名，
并把该目录写入 `~/.profile` 的 `PATH`。

## 5. 验证

```bash
./scripts/99-verify.sh        # 阶段完成后统一校验
```

```bash
for c in git curl vim tmux zsh rg fzf jq sassc sensors; do

done
```

## 6. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `sudo: interactive authentication is required` | 免密 sudo 未配置 | 执行第 1 节命令 |
| `apt-get install` 卡在 `Waiting for headers` | cn.archive 拥堵 | 执行 `./scripts/02-network-mirrors.sh` 换 TUNA |
| 脚本在某一步静默退出 | `set -u` + 未定义变量 | 改用 `set -o pipefail`，变量加 `:-` 默认值 |
| `visudo -c` 报语法错误 | heredoc 里有全角字符 | 删掉文件重新用 ASCII 输入 |
