# 22 · 字体渲染

> 脚本：`scripts/23-font-render.sh`
> 需求：`REQ-35`　关联：`ADR-26`（字体族保持系统默认）

## 1. 边界：只调渲染，不换字体

| 做 | 不做 |
|---|---|
| 调 hinting / hintstyle / rgba / lcdfilter / autohint | 换 Inter / JetBrains Mono（REQ-06 已 reverted） |
| 用 fontconfig 用户级覆盖 | 改 `/etc/fonts` 系统配置 |
| 保留 11pt 正文字号 | 改 gsettings 的 `font-name` / `text-scaling-factor` |

理由：11-03 换字体的收益被"卡顿排查"整批回退（ADR-07），11-07 定为维持系统默认（ADR-26）。
渲染参数是**同一个目标的低成本路径**：不动字体族，也能改善锐利度与字重观感。

## 2. 参数含义与取舍

| 参数 | 默认值 | 作用 | 本机取舍 |
|---|---|---|---|
| `antialias` | `true` | 抗锯齿 | 必开，关掉就是锯齿字 |
| `hinting` | `true` | 字形微调 | 开；关掉小字号会糊 |
| `hintstyle` | `hintslight` | 微调强度 | **默认 `hintslight`**：比 `hintfull` 更接近"字形原样"，比 `none` 锐 |
| `rgba` | `rgb` | 次像素排列 | 见 §4 的诚实说明 |
| `lcdfilter` | `lcddefault` | 次像素滤波 | 配合 `rgba` 才有效 |
| `autohint` | `false` | 忽略字体自带微调 | 关；系统字体自带 hinting 质量更好 |
| `embeddedbitmap` | `false` | 用内嵌点阵 | 关；高分屏下点阵会发虚 |

三档预设（够用即可，不做无限调参）：

```bash
./scripts/23-font-render.sh --install --hintstyle hintslight   # 默认，锐而不刺
./scripts/23-font-render.sh --install --hintstyle hintfull     # 更"实"，小字号更清楚
./scripts/23-font-render.sh --install --hintstyle none         # 最接近字形设计，可能偏软
```

## 3. 落盘位置（为什么不是 fonts.conf）

```
~/.config/fontconfig/conf.d/99-suona-render.conf
```

刻意避开 `~/.config/fontconfig/fonts.conf`：`99-verify.sh` 的
「字体已按回退清理」断言依赖后者不存在（REQ-06 回退态）。另建 `conf.d/` 文件
既能让 fontconfig 生效，又不破坏既有断言——这是 ADR-21「状态感知」的直接应用。

## 4. 诚实边界：Wayland 下 rgba 多半不生效

- GNOME Wayland 会话默认走**灰度抗锯齿**，`rgba`/`lcdfilter` 主要影响 XWayland 与部分 GTK3 应用。
- 因此本脚本**不承诺**「开了 rgb 就一定更清楚」，只保证参数写入正确。
- 判断是否有效只有一个办法：同窗口、同字号、同缩放，截图放大对比（见 §5）。
- 若对比无差异，如实记「本机无差异」，不要写成「渲染优化生效」。

## 5. A/B 对比方法

```bash
# 1) 记录当前匹配结果
./scripts/23-font-render.sh --status

# 2) 改一档
./scripts/23-font-render.sh --install --hintstyle hintfull

# 3) 重开一个应用（已开进程不会重读 fontconfig）
nautilus --new-window &

# 4) 同窗口截图，放大 400% 对比字重与边缘
```

对比时禁止混用不同缩放：`scaling` 不同，像素量不同，观感差异来自缩放而非渲染。

## 6. 常见误区

| 误区 | 事实 |
|---|---|
| 「换 Inter 就能像 macOS」 | 观感差异主要来自字形设计 + 字重 + 抗锯齿，不是族名 |
| 「hintfull 一定更好」 | 小字号更实，大字号会变形，标题尤其明显 |
| 「改了立刻生效」 | fontconfig 在进程启动时读取，必须重开应用 |
| 「rgba 开了就有次像素」 | Wayland 下多数无效果，只有截图能证明 |
| 「字体越细越高级」 | 11pt 正文过细会显著降低可读性，尤其在 3072×1920 高分屏 |

## 7. 回滚

```bash
./scripts/23-font-render.sh --restore     # 只删自己写的 conf.d 文件
```

只删除带 `SuonaOS` 标记的文件；若该路径已被别的工具占用，脚本会跳过而不是覆盖。
