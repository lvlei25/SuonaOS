## 3. 轮换是怎么实现的

GNOME 不支持「指定一个文件夹自动轮换」，只认 **XML 时间轴**。
`water-cycle.xml` 的结构是：

```xml
<background>
  <starttime>…</starttime>
  <static><duration>1800.0</duration><file>…water-01.jpg</file></static>
  <transition><duration>3.0</duration><from>…01</from><to>…02</to></transition>
  … 每张一段 static + transition，末张 to 回到首张 …
</background>
```

`picture-uri` 指向这个 XML，GNOME 就会按时间轴自己切换，**不需要常驻脚本**。

验证（不依赖视觉）：

```bash
python3 -c "
import xml.etree.ElementTree as ET
r=ET.parse('$HOME/Pictures/Wallpapers/water/water-cycle.xml').getroot()
print('static', len(r.findall('static')), 'transition', len(r.findall('transition')))
"
```

## 4. 常用操作

```bash
# 看当前状态
./scripts/10-wallpaper-water.sh --list

# 改成每 10 分钟
./scripts/10-wallpaper-water.sh --interval 600

# 加/换图后重新生成（脚本会扫描 final/*.jpg 重新排时间轴）
cp 新图.jpg ~/Pictures/Wallpapers/water/final/water-05.jpg
./scripts/10-wallpaper-water.sh
```

加图后记得把新图的作者/授权补进 `CREDITS.txt`。

**推荐的新图规格**：宽度 ≥ 3072，比例接近 16:10。处理命令：

```bash
magick 原图.jpg -auto-orient -resize '3072x1920^' -gravity center \
       -extent 3072x1920 -unsharp 0x0.4+0.6+0.02 -quality 90 final/water-05.jpg
```

## 5. 回滚

```bash
# 回到系统默认壁纸
gsettings reset org.gnome.desktop.background picture-uri
gsettings reset org.gnome.desktop.background picture-uri-dark

# 恢复成之前那张星空
gsettings set org.gnome.desktop.background picture-uri \
  'file:///usr/share/backgrounds/mizuno-as-Winter_Grand_Triangle.jpg'
gsettings set org.gnome.desktop.background picture-uri-dark \
  'file:///usr/share/backgrounds/mizuno-as-Winter_Grand_Triangle.jpg'
```

图片本身可以保留，不影响系统。

## 6. 踩坑记录

| 现象 | 原因 | 处理 |
|---|---|---|
| 下载后文件只有 3.2 KB | Commons 文件名猜错，拿到的是 404 HTML | 先 `file xxx.jpg` 确认是 `JPEG image data`；直链只从 API 的 `thumburl` 取 |
| Unsplash 抓不到图 | 搜索页反爬、napi 要鉴权、source 接口停用 | 改用 Wikimedia Commons API |
| 图片两侧被裁 | 原图 1.5~1.78 比例，屏幕 1.6，`zoom` 会居中裁切 | 优先选接近 16:10 的图；或用 `scaled`（会留黑边） |
| 改了图没换 | XML 里写的是绝对路径，旧路径失效 | 重跑脚本重新生成 XML |
