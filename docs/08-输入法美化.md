# 08 · 输入法美化（fcitx5 候选框）

> 脚本：`scripts/08-ime-theme.sh`
> 进程托管：**systemd 用户服务 `fcitx5.service`**（ADR-04）。切换主题后必须
> `systemctl --user restart fcitx5.service`，仅 `fcitx5-remote -r` 不足以刷新主题。

## 1. 现状

系统只自带两套主题：

```
/usr/share/fcitx5/themes/
├── default
└── default-dark
```

`~/.config/fcitx5/conf/classicui.conf` 之前**根本不存在**，也就是说候选框一直用内置默认样式。

## 2. 用了哪两套

| 主题 | 风格 | 来源 | 套数 |
|---|---|---|---|
| **Catppuccin** | 深色、圆角、柔和配色 | `catppuccin/fcitx5` | 4 色调 × 14 强调色 = 56 |
| **Material-Color** | 浅色、细边框、扁平 | `hosxy/Fcitx5-Material-Color` | 10 个颜色 |

合计 **66 套**，全部装在用户目录 `~/.local/share/fcitx5/themes/`，不污染系统。

Catppuccin 的四种色调：

| 色调 | 明暗 | 适用 |
|---|---|---|
| `latte` | 浅色 | 白天/浅色桌面 |
| `frappe` | 中深 | 折中 |
| `macchiato` | 深 | 深色桌面 |
| `mocha` | 最深 | 深色桌面（默认） |

强调色可选 `mauve / blue / teal / green / peach / pink / red / sapphire ...`，
例如 `Catppuccin-mocha-blue`、`Catppuccin-mocha-teal`。

## 3. 圆角是怎么来的

Catppuccin 官方默认是**直角纯色块**，圆角靠两张 SVG 贴图实现，而 `theme.conf` 里默认是注释掉的：

```ini
[InputPanel/Background]
Color=#313244
# Uncomment this to switch to rounded-corner
# Image=panel.svg
```

脚本用 sed 取消注释：

```bash
sed -i -e 's/^#\s*Image=panel\.svg/Image=panel.svg/' \
       -e 's/^#\s*Image=highlight\.svg/Image=highlight.svg/' theme.conf
```

启用 `Image` 后，边距由 `[InputPanel/Background/Margin]` 控制（Catppuccin 里是 10），
**如果圆角看起来被裁掉，就是 Margin 太小**，调到 12~16 即可。

## 4. 配置文件

`~/.config/fcitx5/conf/classicui.conf`：

```ini
Theme=Catppuccin-mocha-mauve
Font="Noto Sans CJK SC 12"
MenuFont="Noto Sans CJK SC 10"
TrayFont="Noto Sans CJK SC Bold 10"
Vertical Candidate List=False
WheelForPaging=True
```

| 键 | 说明 |
|---|---|
| `Theme` | 主题目录名 |
| `Font` | **必须写含中文的字体族**，否则汉字回落到别的字体，候选词宽窄不齐 |
| `Vertical Candidate List` | `True` 竖排候选（适合习惯竖排的用户） |
| `WheelForPaging` | 滚轮翻页 |

> 字体这里写 `Noto Sans CJK SC 12` 而不是 `Inter 12`：Inter 没有汉字，
> fcitx5 逐字回落会导致候选词里中英文字宽和基线不一致，看起来"歪"。

## 5. 切换主题

```bash
# 列出所有已安装主题
./scripts/08-ime-theme.sh --list

# 切换（无需重新下载，立即生效）
./scripts/08-ime-theme.sh --set Catppuccin-mocha-blue
./scripts/08-ime-theme.sh --set Catppuccin-latte-mauve     # 浅色
./scripts/08-ime-theme.sh --set Material-Color-blue        # 扁平浅色
```

也可以直接改一行，然后**重启服务**（不是热重载）：

```bash
sed -i 's/^Theme=.*/Theme=Catppuccin-mocha-teal/' ~/.config/fcitx5/conf/classicui.conf
systemctl --user restart fcitx5.service
```

> `fcitx5-remote -r` 只重载部分配置，classicui 的 `Theme` / `Font` 常不刷新；
> ADR-04 明确规定改主题走服务重启。脚本 `08-ime-theme.sh` 已按此实现。

图形界面预览：`fcitx5-configtool` → 附加组件 → 经典界面 → 主题，
右侧会实时渲染一个候选框样例，改完点「应用」。

## 6. 踩坑记录

### 6.1 `fcitx5 -d` 吞掉 shell 输出

> 主路径由 systemd 服务托管。本节只适用于脚本最后一级的冷启动兜底。

```bash
fcitx5 -d          # 守护进程继承 stdout，管道被一直持有
echo 后续输出      # 永远看不到
```

正确写法：

```bash
setsid fcitx5 -d >/dev/null 2>&1 </dev/null &
```

### 6.2 重启顺序不能反

最初的脚本写成 `pkill -x fcitx5; ...; fcitx5 -d`，
结果 `pkill` 成功、启动失败，**输入法直接没了**。

当前按 ADR-04 三级降级，每级都校验存活：

| 优先级 | 条件 | 动作 | 校验 |
|---|---|---|---|
| 1 | `fcitx5.service` 处于 active | `systemctl --user restart fcitx5.service` | `is-active --quiet` |
| 2 | 无服务托管但进程在 | `fcitx5-remote -r` 热重载 | `pgrep -x fcitx5` |
| 3 | 进程已死 | `setsid fcitx5 -d` 冷启动 | `pgrep -x fcitx5` |

优先交给 systemd 的原因：`Restart=on-failure` 会在崩溃时自动拉起，
而手工 `setsid` 拉起的进程不在服务 cgroup 内，后续 `restart` 管不到它。

### 6.3 主题名与目录名

`Theme=` 填的是**目录名**，不是 `theme.conf` 里的 `Name=`。
Material-Color 原始仓库里所有 `theme-*.conf` 的 `Name` 都叫 `Material-Color`，
脚本会改成 `Material-Color (blue)` 以便在 GUI 列表里区分。

### 6.4 Kimpanel 与候选框主题互斥（重要）

这是本项目在输入法上做的**唯一产品取舍**，记录于 ADR-05 / ISSUE-04。

**现象**：安装 Kimpanel（GNOME Shell 扩展 `kimpanel@kde.org`）+ 启用 fcitx5 侧
kimpanel 插件后，候选框变成黑底灰框——本文所有 `classicui.conf` 配置
（`Theme` / `Font` / 圆角 SVG / 高亮色）**全部失效**，GUI 里改主题也不起作用。

**原因**：Kimpanel 接管了候选框绘制，绕过 fcitx5 的 classicui 渲染路径，
由 GNOME Shell 扩展自己画。两套渲染器不能同时生效。

**收益**：Kimpanel 能让 **GNOME Shell 自身输入框**（活动搜索、重命名文件）
用上 fcitx5 拼音；禁用它则这些输入框回落到内置 ibus。

| 配置 | Shell 输入框 | 普通应用候选框 |
|---|---|---|
| **当前：禁 kimpanel** | ❌ 走内置 ibus | ✅ Catppuccin 主题、圆角、字体全部生效 |
| 启用 Kimpanel | ✅ 可用拼音 | ❌ 黑底灰框、主题全失效 |

**本机选择**：禁用 kimpanel，优先保证日常输入的候选框美观。
`~/.config/fcitx5/config` 中：

```ini
[Behavior/DisabledAddons]
0=kimpanel
```

扩展本身保留安装（不卸载），只是不启用；如需反向选择，
移除上述禁用项、启用扩展并确认 fcitx5 服务重启即可，但**必须接受主题失效**。

> 勘误：`07-输入法.md` 早期把「Shell 输入框无法用 fcitx5」写成架构上的固有限制，
> 实际是此处的配置取舍，2026-11-05 已更正。这一对能力**互斥且无折中方案**，
> 也是 `spec/00-upstream.md` 与 `suonaos/02-technical-spec.md` 中 SR-13 的来源。

## 7. 验收

```bash
systemctl --user is-active fcitx5.service   # active
pgrep -x fcitx5                            # 有 PID
cat ~/.config/fcitx5/conf/classicui.conf | head -3
ls ~/.local/share/fcitx5/themes | wc -l   # 应为 66
fcitx5-configtool                          # 目视确认候选框样式
```

实际输入时观察：候选框圆角是否完整、选中项高亮是否清晰、
中英文混排基线是否对齐。

## 8. 回滚

```bash
# 回到系统默认主题
sed -i 's/^Theme=.*/Theme=default-dark/' ~/.config/fcitx5/conf/classicui.conf
systemctl --user restart fcitx5.service

# 或彻底清除
rm -rf ~/.local/share/fcitx5/themes
rm -f ~/.config/fcitx5/conf/classicui.conf
systemctl --user restart fcitx5.service
```
