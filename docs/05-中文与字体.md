# 05 · 中文与字体渲染

> 脚本：`scripts/05-cjk-fonts.sh`

## 1. 字体选型

| 用途 | 字体 | 包 | 理由 |
|---|---|---|---|
| 界面 | **Inter** | `fonts-inter` | WhiteSur 官方推荐，SF Pro 的开源近似体，字重齐全 |
| 终端/代码 | **JetBrains Mono** | `fonts-jetbrains-mono` | 连字支持好，0/O、1/l/I 区分明显 |
| 中文 | **Noto Sans CJK SC** | `fonts-noto-cjk` | 系统自带，Shapes 齐全，避免混排跳动 |
| Emoji | Noto Color Emoji | `fonts-noto-color-emoji` | |

本机原有中文字体文件 90 个（Noto CJK 全家桶已齐），所以**不需要再下载大型中文包**。
真正缺的是「界面/等宽」这两类西文字体，以及渲染参数。

## 2. fontconfig 调优

配置文件：`~/.config/fontconfig/fonts.conf`（用户级，不影响其他账户）

### 渲染参数

```xml
<match target="font">
  <edit name="antialias" mode="assign"><bool>true</bool></edit>
  <edit name="hinting" mode="assign"><bool>true</bool></edit>
  <edit name="hintstyle" mode="assign"><const>hintslight</const></edit>
  <edit name="rgba" mode="assign"><const>rgb</const></edit>
  <edit name="lcdfilter" mode="assign"><const>lcddefault</const></edit>
  <edit name="autohint" mode="assign"><bool>false</bool></edit>
</match>
```

| 参数 | 取值 | 影响 |
|---|---|---|
| `hintstyle` | `hintslight` | 只对齐竖直方向，笔画粗细保留更自然；`hintfull` 在小字号发糊，`hintnone` 在 1080p 下发虚 |
| `rgba` | `rgb` | 笔记本内置屏通常是 RGB 排列，开亚像素渲染字体更清晰 |
| `lcdfilter` | `lcddefault` | 配合 rgba 使用 |
| `autohint` | `false` | 用字体自带的 hint 信息，Noto/Inter 的 hint 质量优于 freetype 自动 hint |

> 如果外接显示器是 BGR 排列或 OLED，把 `rgb` 改成 `bgr` / `none`，
> 否则文字边缘会有彩边。

### 字体族优先级

```xml
<alias><family>sans-serif</family><prefer>
  <family>Inter</family>
  <family>Noto Sans CJK SC</family>
</prefer></alias>
```

`prefer` 列表的含义：英文用 Inter，Inter 没有的字符（汉字）自动回落到 Noto Sans CJK SC。
这是中英混排最关键的一条——不设置的话，某些应用会拿 DejaVu Sans 硬撑，汉字变成方块或粗细不一。

等宽同理：

```xml
<alias><family>monospace</family><prefer>
  <family>JetBrains Mono</family>
  <family>Noto Sans Mono CJK SC</family>
</prefer></alias>
```

### 中文偏粗修正

```xml
<match target="pattern">
  <test name="lang" compare="contains"><string>zh</string></test>
  <test name="weight" compare="less_eq"><const>medium</const></test>
  <edit name="weight" mode="assign"><const>regular</const></edit>
</match>
```

原因：Noto Sans CJK 的 Regular 在相同磅值下视觉重量比 Inter 重，
很多应用会请求 `medium` 让西文更清楚，结果中文变得过粗。这条规则把中文的
`<=medium` 权重压回 `regular`，中英混排视觉重量更协调。

### 微软字体映射

```xml
<alias binding="same"><family>Microsoft YaHei</family><accept><family>Noto Sans CJK SC</family></accept></alias>
<alias binding="same"><family>SimSun</family><accept><family>Noto Serif CJK SC</family></accept></alias>
```

WPS/Office 文档里硬编码「微软雅黑」「宋体」时，避免回落到字体缺失提示。

## 3. GNOME 字体设置

```bash
gsettings set org.gnome.desktop.interface font-name            'Inter 11'
gsettings set org.gnome.desktop.interface document-font-name   'Inter 12'
gsettings set org.gnome.desktop.interface monospace-font-name  'JetBrains Mono 11'
gsettings set org.gnome.desktop.wm.preferences titlebar-font   'Inter Bold 11'
```

字号说明：13 寸 1920×1200 屏，11pt 是 GNOME 默认 11 的等值替换；
若外接 4K 需要开缩放而不是加字号。

## 4. 验证

```bash
fc-match 'sans-serif:lang=zh'        # 应回落 Noto Sans CJK SC
fc-match monospace                    # 应命中 JetBrains Mono
fc-match Inter
fc-list :lang=zh | wc -l             # 中文字体数量
gsettings get org.gnome.desktop.interface font-name
```

当前结果：

```
中文首选: NotoSansCJK-Regular.ttc: "Noto Sans CJK SC" "Regular"
Inter:    Inter
JetBrains: JetBrains Mono
中文字体数: 90
```

## 5. 常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 改了配置没变化 | fontconfig 缓存 | `fc-cache -fv` |
| 汉字显示为方块 | 缺 CJK 字体 | `sudo apt install fonts-noto-cjk` |
| 汉字忽粗忽细 | 应用自己指定了字体权重 | 检查上面的 `weight` 规则是否被覆盖 |
| 终端中文宽度不对 | 用了非等宽中文回退 | 确认 `Noto Sans Mono CJK SC` 在 monospace 的 prefer 列表里 |
| 文字边缘有彩边 | `rgba` 与屏幕子像素排列不符 | 改 `rgb` → `bgr` → `none` 逐个试 |

## 6. 回滚

```bash
rm ~/.config/fontconfig/fonts.conf
fc-cache -f
./scripts/rollback.sh --restore <RUN_ID> --only /home/suonaos/.config/fontconfig/fonts.conf
```

> **当前实际采用系统默认**（ADR-07 / ADR-26）：界面 `Adwaita Sans 11`、
> 文档 `Adwaita Sans 12`、等宽 `Ubuntu Sans Mono 11`、标题 `Adwaita Sans Bold 11`。
> 本文第 1、3 节描述的是「定制态」，`fonts-inter` / `fonts-jetbrains-mono` 与
> `~/.config/fontconfig/fonts.conf` 均已装好但未启用；想切回定制态只需重跑
> `./scripts/05-cjk-fonts.sh`（幂等，第 3 步重设 4 项 gsettings）。
> `99-verify.sh` 对字体做状态感知断言，两种状态都应零失败。

GNOME 字体恢复默认：

```bash
gsettings reset org.gnome.desktop.interface font-name
gsettings reset org.gnome.desktop.interface document-font-name
gsettings reset org.gnome.desktop.interface monospace-font-name
gsettings reset org.gnome.desktop.wm.preferences titlebar-font
```
