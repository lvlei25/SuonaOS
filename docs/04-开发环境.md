# 04 · 开发环境

> 脚本：`scripts/04-devtools.sh`　配置源：`dotfiles/`

## 1. 设计原则：dotfiles 与 home 单向软链

所有配置文件的**真身**在项目里，`~` 下只是软链：

```
~/.zshrc               -> linux-tune_SuonaOS/dotfiles/zsh/.zshrc
~/.tmux.conf           -> linux-tune_SuonaOS/dotfiles/tmux/.tmux.conf
~/.vimrc               -> linux-tune_SuonaOS/dotfiles/vim/.vimrc
~/.config/starship.toml -> linux-tune_SuonaOS/dotfiles/starship.toml
```

好处：

1. 改配置 = 改项目文件，自动进入版本管理视野；
2. 换机器只跑一遍脚本就恢复；
3. 软链创建前若发现是实体文件，会先 `backup_file` 备份，不会丢原配置。

**改配置请改 `dotfiles/` 下的源文件，不要改 `~` 下的软链指向内容**（虽然是同一个文件，
但编辑器可能因原子写把软链替换成实体文件，之后脚本会认为「非软链」）。

## 3. zsh 配置要点

`dotfiles/zsh/.zshrc` 结构：

| 段落 | 内容 |
|---|---|
| 基础 | `EDITOR=vim`、`LESS=-R -F -X`、HISTSIZE 50000 |
| 历史 | `HIST_IGNORE_ALL_DUPS` + `SHARE_HISTORY`，多窗口共享且去重 |
| 补全 | `compinit -i`（跳过不安全目录检查，加快启动） |
| 插件 | autosuggestions（灰色建议）、syntax-highlighting（命令染色） |
| 提示符 | starship，配置在 `starship.toml`（Tokyo Night 配色） |
| 别名 | `ll/la/lt`、`..`、`ports`、`meminfo`、`sys`、`gs/gl` |
| 环境 | fcitx5 相关变量、npm 全局目录、GOPROXY/rustup 镜像 |

`sys` 别名很实用：

```bash
alias sys='systemd-analyze; systemd-analyze blame | head -15'
```

**性能注意**：`compinit` 会缓存到 `~/.zcompdump`，
`fastfetch` 只在 `[ -t 1 ]` 且交互 shell 时打印，避免污染脚本输出。

## 4. tmux 配置要点

| 项 | 值 | 说明 |
|---|---|---|
| 前缀 | `C-a` | 保留 `C-b` 给 shell 的 backward-char |
| 分屏 | `C-a \|` 竖切 / `C-a -` 横切 | 沿用 vim 直觉 |
| 切换窗格 | `C-a h/j/k/l` | 可重复按（`-r`） |
| 复制 | vi 模式 + `y` 送 `wl-copy` | Wayland 系统剪贴板 |
| 主题 | Tokyo Night 手写配色 | 与 starship 一致 |
| 其他 | `mouse on`、`history-limit 100000`、`focus-events on` | |

首次使用需重新加载：`tmux source-file ~/.tmux.conf`。

## 5. vim 配置要点

零插件，纯原生：

- `number` + `relativenumber` 混合行号
- `expandtab` + 4 空格，Python/JS/YAML 自动 2 空格
- `undofile` 持久化撤销历史到 `~/.vim/undo`
- `fileencodings=utf-8,gbk,gb18030,latin1` —— 打开 GBK 老文件不乱码
- `inoremap jk <Esc>`、`<leader>` 设为空格
- `BufWritePre` 自动去行尾空格

## 6. Python / Node 工具链

```bash
pipx install uv          # uv 装在独立 venv，避免污染系统 python
npm config set registry https://registry.npmmirror.com
```

`uv` 通过 pipx 安装，落在 `~/.local/bin/uv`。注意：**非交互 shell 不会读取 `~/.profile`**，
所以脚本里显式 `export PATH="$HOME/.local/bin:$PATH"`，
否则会出现「装好了但 `uv` 找不到」的假失败。

## 7. 默认 shell

```bash
sudo chsh -s /usr/bin/zsh suonaos
```

用 `sudo chsh` 而不是 `chsh`，因为后者要交互输入密码。
修改写入 `/etc/passwd`，**下次登录生效**（当前会话仍是 bash）。

## 9. 常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| `uv: 未找到命令` | `~/.local/bin` 不在 PATH | 重新登录，或 `export PATH=$HOME/.local/bin:$PATH` |
| zsh 启动报 `command not found: compinit` | `zsh` 包不完整 | `sudo apt install --reinstall zsh` |
| tmux 里复制不到系统剪贴板 | 缺 `wl-copy` | `sudo apt install wl-clipboard` |
| starship 不显示图标 | 终端字体不是 Nerd Font | 当前用 JetBrains Mono（无 Nerd 图标），可换 `JetBrainsMono Nerd Font` |
| 改 dotfiles 不生效 | 编辑器把软链写成了实体文件 | `./scripts/04-devtools.sh` 重新链接（会先备份） |
