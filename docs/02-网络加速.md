# 02 · 网络加速

> 脚本：`scripts/02-network-mirrors.sh`
> 用法：`./scripts/02-network-mirrors.sh [--apt] [--pip] [--npm] [--github] [--all]`

## 1. apt 源

Ubuntu 24.04 起 apt 使用 **deb822 格式**（`/etc/apt/sources.list.d/ubuntu.sources`），
不再是 `/etc/apt/sources.list` 的 `deb http://...` 单行格式。因此替换镜像要改 `URIs:` 字段。

原始配置：

```
URIs: http://cn.archive.ubuntu.com/ubuntu/
Suites: resolute resolute-updates resolute-backports
URIs: http://security.ubuntu.com/ubuntu/
Suites: resolute-security
```

替换为 TUNA（只用一条 sed 同时覆盖 archive / security）：

```bash
sudo sed -i \
  -e "s|http://cn.archive.ubuntu.com/ubuntu/|https://mirrors.tuna.tsinghua.edu.cn/ubuntu/|g" \
  -e "s|http://archive.ubuntu.com/ubuntu/|https://mirrors.tuna.tsinghua.edu.cn/ubuntu/|g" \
  -e "s|http://security.ubuntu.com/ubuntu/|https://mirrors.tuna.tsinghua.edu.cn/ubuntu/|g" \
  /etc/apt/sources.list.d/ubuntu.sources
```

TUNA 同一个 `ubuntu/` 仓库里同时提供 `resolute-security`，所以 security 也指向同一个 URI。

实测：替换后 `apt update` 11 秒完成，下载 `systemd-zram-generator` 约 440 kB/s ~ 1 MB/s。

> 脚本会先用 `backup_file` 备份 `ubuntu.sources`，回滚只需
> `./scripts/rollback.sh --restore <RUN_ID> --only /etc/apt/sources.list.d/ubuntu.sources`

## 2. pip

写入 `~/.config/pip/pip.conf`：

```ini
[global]
index-url = https://mirrors.tuna.tsinghua.edu.cn/pypi/web/simple
trusted-host = mirrors.tuna.tsinghua.edu.cn
timeout = 30

[install]
upgrade-strategy = only-if-needed
```

`upgrade-strategy = only-if-needed` 的作用是避免 `pip install` 时把依赖连带升级，
减少无谓的下载与版本冲突。

## 3. npm

```bash
npm config set registry https://registry.npmmirror.com
```

写入 `~/.npmrc`，只影响当前用户，不影响系统级 `/usr/etc/npmrc`。

## 4. GitHub

国内直连 `github.com` 的 git 协议经常超时，但 raw 与 release 镜像可用。
脚本采用 **git 的 url 重写**机制：

```bash
git config --global url."https://ghfast.top/https://github.com/".insteadOf "https://github.com/"
```

效果：`git clone https://github.com/user/repo` 实际请求
`https://ghfast.top/https://github.com/user/repo`。

实测克隆 WhiteSur 三个仓库（约 90 MB）耗时 8s / 9s / 7s。

**注意事项：**

| 场景 | 说明 |
|---|---|
| 私有仓库 | 加速镜像不转发认证头，会 401。此时用 `git config --global --unset url.https://ghfast.top/https://github.com/.insteadOf` 临时撤销 |
| SSH 克隆 | `git@github.com:` 不受影响（insteadOf 只匹配 https） |
| 已完成克隆 | 本项目的 WhiteSur 源码已缓存到 `vendor/`，重装主题不需要再联网 |

## 5. 其他镜像（已写入 `~/.zshrc`）

```bash
export GOPROXY=https://goproxy.cn,direct
export RUSTUP_DIST_SERVER=https://rsproxy.cn
export RUSTUP_UPDATE_ROOT=https://rsproxy.cn/rustup
```

## 6. 验证

```bash
grep -E '^URIs' /etc/apt/sources.list.d/ubuntu.sources   # 应为 mirrors.tuna
cat ~/.config/pip/pip.conf
npm config get registry                                   # 应为 npmmirror
git config --global --get-regexp 'url\..*insteadof'
```

```bash
        /etc/apt/sources.list.d/ubuntu.sources
rm ~/.config/pip/pip.conf

git config --global --unset url.https://ghfast.top/https://github.com/.insteadOf
```
