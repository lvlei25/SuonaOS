# 06 · WhiteSur 主题美化（macOS 风）

> 脚本：`scripts/06-theme-whitesur.sh [--light|--dark]`（默认 dark）

## 1. 方案构成

| 组件 | 仓库 | 安装位置 |
|---|---|---|
| GTK2/3/4 + GNOME Shell 主题 | `vinceliuice/WhiteSur-gtk-theme` | `~/.themes/WhiteSur-Dark` |
| 图标 | `vinceliuice/WhiteSur-icon-theme` | `~/.icons/WhiteSur-dark` |
| 光标 | `vinceliuice/WhiteSur-cursors` | `~/.icons/WhiteSur-cursors` |

全部装在用户目录，**不碰 `/usr/share/themes`**，卸载只需删目录 + 重置 gsettings。

## 2. 编译依赖（容易踩坑）

```bash
sudo apt install sassc libglib2.0-dev-bin gnome-shell-extension-user-theme
```

| 包 | 提供 | 缺失后果 |
|---|---|---|
| `sassc` | SCSS 编译器 | `install.sh` 报 `sassc: not found`，主题完全建不出来 |
| `libglib2.0-dev-bin` | `glib-compile-resources` | Shell 主题的 `.gresource` 编译失败，顶栏没变化 |
| `gnome-shell-extension-user-theme` | `user-theme@...` 扩展 | 只能换 GTK 主题，**换不了顶栏/概览** |

## 3. 安装流程

```bash
cd vendor/WhiteSur-gtk-theme
./install.sh -t all -c dark -l -d ~/.themes
```

| 参数 | 含义 |
|---|---|
| `-t all` | 生成全部变体（含 solid / 各强调色 / hidpi） |
| `-c dark` | 深色 |
| `-l` | 同时生成 libadwaita 资源到 `~/.config/gtk-4.0/` |
| `-d ~/.themes` | 装到用户目录（不加 `-d` 且无 sudo 时默认也是家目录） |

`-l` 很关键：GNOME 50 下大量应用是 libadwaita（GTK4），
不生成 `~/.config/gtk-4.0/gtk.css` 的话这些应用仍是默认 Adwaita 外观，
会出现「文件管理器变白了、设置没变」的割裂感。

图标：

```bash
cd vendor/WhiteSur-icon-theme && ./install.sh -d ~/.icons -a
```

`-a` 表示生成全部配色变体。

## 4. 应用设置（`gsettings` 对照表）

| 设置 | 值 | 作用 |
|---|---|---|
| `interface gtk-theme` | `WhiteSur-Dark` | GTK2/3 应用外观 |
| `interface icon-theme` | `WhiteSur-dark` | 图标（**注意小写**） |
| `interface cursor-theme` | `WhiteSur-cursors` | 光标 |
| `interface color-scheme` | `prefer-dark` | 让 libadwaita 走暗色 |
| `wm.preferences button-layout` | `close,minimize,maximize:` | 红绿灯移到窗口左上角 |
| `extensions.user-theme name` | `WhiteSur-Dark` | GNOME Shell 主题 |

### ⚠️ 陷阱一：图标主题名大小写

GTK 主题是 `WhiteSur-Dark`（大写 D），图标目录却是 `WhiteSur-dark`（小写 d）。
设成 `WhiteSur-Dark` 不会报错，只会**静默不生效**（回落到默认图标）。
用 `ls ~/.icons` 确认实际目录名。

### ⚠️ 陷阱二：新装的扩展在本会话"不存在"

```bash
$ gnome-extensions enable user-theme@gnome-shell-extensions.gcampax.github.com
扩展"user-theme@..."不存在
```

原因：GNOME Shell 在会话启动时缓存了扩展列表，新装到
`/usr/share/gnome-shell/extensions/` 的扩展当次会话不可见，
`gnome-extensions` 命令查询的是 Shell 的 D-Bus 接口而非磁盘。

解决：直接写 gsettings，注销重登后由 Shell 加载：

```bash
gsettings set org.gnome.shell enabled-extensions \
  "['ding@rastersoft.com', 'ubuntu-dock@ubuntu.com', 'tiling-assistant@ubuntu.com', \
    'snapd-search-provider@canonical.com', 'web-search-provider@ubuntu.com', \
    'user-theme@gnome-shell-extensions.gcampax.github.com']"
```

## 5. Dock（底部悬浮 macOS 风）

Ubuntu Dock 是 dash-to-dock 的衍生，schema 为 `org.gnome.shell.extensions.dash-to-dock`：

```bash
DS=org.gnome.shell.extensions.dash-to-dock
gsettings set $DS dock-position BOTTOM      # 底部
gsettings set $DS extend-height false       # 不占满整行，悬浮居中
gsettings set $DS dock-fixed false
gsettings set $DS autohide true             # 自动隐藏
gsettings set $DS intellihide true          # 有窗口挡住时隐藏
gsettings set $DS dash-max-icon-size 44     # macOS 风格大图标
gsettings set $DS transparency-mode FIXED
gsettings set $DS background-opacity 0.55   # 半透明毛玻璃感
gsettings set $DS running-indicator-style DOTS
gsettings set $DS click-action minimize-or-previews
```

`extend-height false` + `dock-position BOTTOM` 是「macOS Dock」观感的核心，
不加这两条就是一个贴底的普通任务栏。

## 6. 切换配色与明暗

```bash
./scripts/06-theme-whitesur.sh --light      # 浅色版
# 换强调色：直接改 gsettings，主题已生成全部变体
gsettings set org.gnome.desktop.interface gtk-theme 'WhiteSur-Dark-blue'
gsettings set org.gnome.desktop.interface icon-theme 'WhiteSur-dark'   # 图标只有 dark/light
```

可用强调色：`blue / green / grey / orange / pink / purple / red / yellow`，
每个都有 `-solid`（不透明）与 `-hdpi / -xhdpi`（高分屏）变体。

## 7. 生效范围与限制

| 范围 | 是否生效 | 说明 |
|---|---|---|
| GTK3 应用（Nautilus、gedit） | ✅ 立即 | |
| libadwaita 应用（设置、软件） | ✅ 需重启应用 | 依赖 `~/.config/gtk-4.0/gtk.css` |
| GNOME Shell（顶栏、概览、菜单） | ⚠️ **注销重登** | user-theme 扩展需重新加载 |
| Snap 应用（Firefox/Chromium） | ⚠️ 部分 | snap 沙箱读不到 `~/.themes`，需 `snap connect` 或改用 deb |
| 输入法候选窗 | ❌ | fcitx5 使用自己的主题，在 `fcitx5-configtool` 里单独配 |

## 8. 完全卸载

```bash
gsettings reset org.gnome.desktop.interface gtk-theme
gsettings reset org.gnome.desktop.interface icon-theme
gsettings reset org.gnome.desktop.interface cursor-theme
gsettings reset org.gnome.desktop.wm.preferences button-layout
gsettings set org.gnome.desktop.interface color-scheme default
rm -rf ~/.themes ~/.icons ~/.config/gtk-4.0
sudo apt remove gnome-shell-extension-user-theme
```

源码缓存在 `vendor/`，卸载后可保留以便离线重装。
