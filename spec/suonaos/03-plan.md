## 编排原则

1. **先核验再排期**：SM-0/1 状态未知，任何新排期都需先补核验（吸取原型阶段「配置写了不等于进程加载了」的教训）。
2. **裁决优先于开发**：SDEC-01/02 直接决定采购与合规口径，未裁决前不启动批量适配。
3. **可量化验收**：每个里程碑绑定 `05-acceptance-risks.md` 的指标，不用「完成」「调好」这类模糊词。
4. **原型先行**：`linux-tune` 的脚本可在 UM870 到货前先在原型机验证逻辑，但 LLM / 功耗 / 续航指标必须在目标机型实测。
5. **全文档化**：[报告 10.2] 每个决策进本 spec，每条命令进 Git，每台机器建兼容性档案。
