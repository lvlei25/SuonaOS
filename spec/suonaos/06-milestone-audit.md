## C. 客观取证命令（只读，在本机执行后贴回输出）

```bash
# 位置：~　sudo：否　只读
cd ~/CodeBuddy/work/linux-tune_SuonaOS

echo '=== 域名（需联网，查持有状态而非本机记录）==='
for d in suonaos.com suonaos.org; do
  printf '%s: ' "$d"; whois "$d" 2>/dev/null | grep -iE '^(domain name|registrar|expiry date)' | head -3 || echo 'whois 不可用'
done

echo '=== 本地是否有硬件/镜像/团队证据 ==='
find . -type f \( -iname '*um870*' -o -iname '*compat*' -o -iname '*v0.1*' \
     -o -iname '*domain*' -o -iname '*trademark*' \) 2>/dev/null | head -20

echo '=== 8 步工具齐备情况 ==='
for s in 00-preflight preboot-check bench 99-verify rollback llm-verify; do
  [ -f "scripts/$s.sh" ] && printf '  OK   %s\n' "$s.sh" || printf '  --   %s.sh 未建\n' "$s"
done

echo '=== 是否已有填写过的核验副本 ==='
ls -1 spec/suonaos/06-milestone-audit-*.md 2>/dev/null || echo '（尚无）'
```

> 说明：本机是 T14 Gen 5 原型机，**不是 UM870**。上面命令只能查「证据文件是否留存」，
> 硬件实物、域名持有、人员到岗必须附外部凭证（截图/发票/订单/邮件），不能靠命令推断。
