# 01 · 产品定义与需求

来源：《立项报告 v1.0》01 / 02 / 04 章。

## 定位

不是「另一个 Ubuntu 衍生版」，而是卖给中国大陆一人公司（OPC）的**预装整机**：
Ubuntu 26.04 深度调优 + 国产软件开箱即用 + 本地 14B LLM 一键启动 + 锁定机型。
[报告 00] 一句话立项建议：值得立项，3 个月 MVP 整机、6 个月公开发行。

## 目标用户（6 类）[报告 1.1]

| 人群 | 核心痛点 | 产品应答 |
|---|---|---|
| 独立开发者 | Mac mini 贵、想跑 14B、不想折腾装系统 | 开发即用 + 本地 LLM + 低 40% 价格 |
| 内容创作者 | 装系统打断创作、协同工具多 | 国产软件栈 + 14B 文案辅助 + OBS/Blender |
| 设计师 | Adobe 年费高、开源替代品配置难 | Blender/Krita/Penpot 预装 + 色彩管理调好 |
| 小微电商 | 多后台常卡死、不懂装系统 | 多账号隔离 + 微信多开 + 飞书集成 |
| 咨询顾问 | 稳定安全、文件不能上云 | WPS + 本地加密 + 会议三合一 |
| AI 创业者 | 云端 API 贵、ROCm 配置劝退 | ROCm + Ollama + 14B 预下载 |
